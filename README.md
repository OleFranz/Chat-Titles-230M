# Chat-Titles-230M

Chat-Titles-230M is a small chat-title generator fine-tuned on the `ogrnz/chat-titles` dataset, based on `unsloth/LFM2.5-230M`.

## Examples
| Message | Title |
| --- | --- |
| Can you summarize the key points from the meeting transcript? | Meeting Transcript Summary |
| My laptop battery drains fast after the latest update. Any ideas? | Laptop Battery Drainage |
| Write a short, friendly email to reschedule a call for next week. | Rescheduling Call Request |
| I need a workout plan for beginners that I can do at home. | Beginner Home Workout Plan |
| Please explain the difference between HTTP and HTTPS in simple terms. | HTTP vs HTTPS Explanation |
